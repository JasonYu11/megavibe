# Megavibe

Megavibe is a community for building ambitious ideas with agents.

We explore how AI agents can turn strange, useful, experimental, and practical ideas into real workflows, prototypes, automations, tools, and products.

## What This Community Does

- Share agent experiments and lessons learned
- Turn ideas into buildable projects
- Build useful automations and workflows
- Match collaborators around promising ideas
- Document reusable prompts, agent patterns, and toolchains
- Showcase demos, prototypes, and releases

## Community Structure

| Area | Purpose |
| --- | --- |
| `ideas/` | Raw ideas, project proposals, and open questions |
| `projects/` | Active project pages and progress tracking |
| `experiments/` | Agent experiments, failures, observations, and results |
| `workflows/` | Reusable agent workflows, prompts, and automation patterns |
| `demos/` | Finished demos, screenshots, videos, and launch notes |
| `resources/` | Tools, references, models, services, and learning materials |
| `weekly-logs/` | Weekly build notes from members |

## How To Participate

1. Open an issue with an idea, experiment, or project proposal.
2. Use Discussions for broad questions, reflections, and collaboration.
3. Create a project page when an idea becomes active.
4. Share weekly progress in `weekly-logs/`.
5. Submit reusable workflows, demos, or resources through pull requests.

## Project Status Labels

- `idea`: early idea or open concept
- `proposal`: structured project proposal
- `building`: active work in progress
- `experiment`: test, trial, or research note
- `demo`: working output or public showcase
- `help-wanted`: looking for collaborators
- `beginner-friendly`: good first contribution

## Weekly Rhythm

- Monday: post or update project goals
- Wednesday: share blockers and experiments
- Friday: publish build logs
- Monthly: collect the best demos and lessons

## Repository Rules

- Prefer concrete artifacts over vague discussion.
- Document failures as clearly as successes.
- Link prompts, tools, data, code, and demos when possible.
- Keep project pages short enough to scan and detailed enough to continue.
