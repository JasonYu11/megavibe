# Ideas

Use this folder for ideas that may become projects.

## Idea Template

```markdown
# Idea Name

## Summary

One paragraph.

## Why It Matters

Who needs this and why?

## Possible Agent Approach

What could agents automate, generate, inspect, or coordinate?

## Expected Output

Prototype, workflow, website, bot, report, dataset, automation, or demo.

## Needed Skills

Design, coding, research, operations, domain knowledge, data, testing.

## Next Step

The smallest useful experiment.
```
