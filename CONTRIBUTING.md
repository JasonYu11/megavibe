# Contributing To Megavibe

Megavibe is organized around ideas, experiments, workflows, and projects.

## Good Contributions

- A clear idea with a target user or use case
- An experiment report with setup, result, and lesson
- A reusable agent workflow or prompt pattern
- A project update with next steps
- A demo with a link, screenshot, or instructions
- A useful resource with a short explanation

## Contribution Flow

1. Start with an issue if the contribution changes direction or proposes a new project.
2. Use a pull request for documents, workflows, demos, and project pages.
3. Keep changes focused.
4. Include links to related issues, demos, repositories, or discussions.

## Writing Style

- Be specific.
- Show the actual result.
- Include enough context for someone else to reproduce or continue the work.
- Mark uncertain claims as uncertain.

## Project Page Template

```markdown
# Project Name

## One-Line Goal

What are we trying to build?

## Status

Idea / Building / Testing / Released / Paused

## Owner

GitHub handle or name.

## Collaborators

Who is involved?

## Target User

Who benefits from this?

## Agent Stack

Models, tools, frameworks, automations, integrations.

## Current Progress

What works now?

## Blockers

What is stuck?

## Next Steps

The next 1-3 concrete actions.

## Links

Demo, repository, notes, docs, screenshots.
```
